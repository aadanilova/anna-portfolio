# anna-portfolio

Сайт-портфолио Анны, графического дизайнера: мерч, упаковка, промопродукция, POS-материалы и карточки для маркетплейсов.

Статический одностраничный сайт (HTML, CSS, vanilla JS) для публикации на GitHub Pages. Сборка не нужна.

## Структура

```
index.html        разметка и тексты
styles.css        стили (светлая + автоматическая тёмная тема)
script.js         появление секций, счётчики, tilt карточек, модалка
assets/favicon.svg
assets/og.jpg     превью для соцсетей 1200×630
assets/works/     изображения работ
```

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
3. Через 1–2 минуты сайт будет по адресу https://hlwktt.github.io/anna-portfolio/

## Изображения работ

Обложка карточки: `assets/works/<slug>.jpg`, 1600×1000, JPG/WebP до 300 КБ.
Галерея в модалке: `assets/works/<slug>-01.jpg`, `-02.jpg`…, длинная сторона до 1600 px, до 300 КБ.
Пока файла нет, карточка показывает CSS-плейсхолдер.

| slug | статус |
|---|---|
| gazprombank | обложка и 1 фото есть; нужны коробка настольной игры и рюкзаки |
| uniel-tea | нет изображений |
| moscow-cats | нет изображений |
| f6-candles | нет изображений |
| new-year-merch | есть |
| marketplaces | есть |

После добавления файла пропишите `<img>` в `<template class="case-details">` нужной карточки в `index.html`.
